# Twitter Database Simulation (MySQL) 🐦

مشروع تصميم وبناء قاعدة بيانات متكاملة لمحاكاة منصة تويتر، تم تطبيقه كمشروع نهائي لدورة قواعد البيانات في **منصة سطر (Satr)**.

## 🗂️ هيكل الجداول (Tables)
* **Users:** حفظ بيانات المستخدمين الأساسية وتشفير كلمات المرور باستخدام دالة `MD5()`.
* **Profiles:** حفظ معلومات الملف الشخصي (الاسم والنبذة) بعلاقة (واحد لواحد) مع المستخدم.
* **Follows:** إدارة نظام المتابعة بين الحسابات.
* **Tweets:** تخزين التغريدات وربطها بصاحبها وتاريخ النشر.
* **Likes:** تسجيل الإعجابات وربطها بالمستخدم والتغريدة.

## ⚙️ الوظائف البرمجية (Stored Procedures)
* **`createAccount`:** إنشاء حساب جديد وتشفير كلمة المرور وإضافة الملف الشخصي تلقائياً.
* **`User_Follow`:** تنفيذ عملية المتابعة بين مستخدمين باستخدام أسماء الحسابات.
